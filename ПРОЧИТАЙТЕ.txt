Это подготовленная папка репозитория https://github.com/ildarito/Markov-Chain-Driver.

Здесь один основной скрипт run_three_scenarios.py, requirements.txt, README,
.gitignore, три рассчитанные MAT-модели и их контрольные суммы.
Исходные логи и сетевые пути в публикуемую папку не включены.
Лицензия автоматически не назначалась.

Установка и запуск из этой папки:
  python -m pip install -r requirements.txt
  python run_three_scenarios.py --data "D:\мои_логи"

В вашей прежней программе сетевые пути оставлены без изменений.
README и .gitignore на сайте GitHub повторно добавлять не нужно.

Если в этой папке уже настроен Git и сделан локальный коммит,
отправьте файлы из своего терминала командой:
  git push -u origin main
При необходимости Git откроет вход в вашу учётную запись GitHub.
Пароль или токен не нужно передавать в переписке.
